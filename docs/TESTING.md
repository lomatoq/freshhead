# Проверки версии 0.1

## Автоматические тесты

`python -m pytest -q`: **49 passed** в Linux и Windows. На Windows есть предупреждение о deprecated alias в зависимости Starlette/AnyIO, без падения тестов.

Проверены цены и номера моделей, JSON-LD, границы карточек и расцветок, сжатые HTTP-ответы, запуск refresh на event loop, ограничения доменов/redirects, robots.txt, стабильные ID, сохранение лайков, фильтры, раздельные демо/реальные предпочтения, состав и сохранение образов, API-защита и фиксация доставки только после ответа Telegram. Сетевые unit-тесты используют фиктивные ответы.

## Проверка интерфейса

Chromium: **11 сценариев**, desktop 1440×1120 и mobile 390×844; ошибок JavaScript и горизонтального переполнения мобильной страницы не выявлено. Проверены лента, лайк и пропуск, undo, сборка и сохранение образа, источники, настройки, избранное и ежедневный экран.

Это офлайн-рендер собственных HTML/CSS/JS с реальным FastAPI TestClient и демонстрационными товарами. Прямой браузерный переход к localhost в тестовой среде был заблокирован её политикой; политика не изменялась. Эти скриншоты не являются проверкой внешних магазинов или реальных фотографий.

## Реальные магазины и запущенный сервер

25 сентября 2026 года выполнен отдельный сетевой прогон с Windows, без обхода ограничений сайтов: **Supersklep — 483 сохранённые карточки; EME Studios — 40; Walk in Paris — 51**. Всего 574 реальные записи, 572 с полем цены и 550 с непустой ссылкой на изображение. Работоспособность каждой фотоссылки отдельно не проверялась. Проход ограничен бюджетом запросов и не является полной индексацией магазинов.

**Jaded London вернул HTTP 404**, товары не получены. Адаптер оставлен экспериментальным; четыре настроенных источника не означают четыре подтверждённо работающих магазина. EME использует US-витрину; цены сохраняются в исходной валюте. Доставка, региональные цены и индивидуальные размеры требуют проверки у продавца.

После исправления двойной распаковки HTTP и границ карточек повторный сбор прошёл для трёх указанных источников. Неполные неоценённые миниатюры расцветок из первоначального тестового импорта удалены; они остаются ссылками для последующего чтения карточек, без заимствования цены основного товара.

Приложение запущено на `http://127.0.0.1:8766`: `/health` вернул `ok: true`, `/api/state` — 574 товара и 0 демо, а `POST /api/outfits` в режиме contrast — **6 образов из реального каталога**. Это проверка работы кода, не оценка эстетического качества рекомендаций. Сервер, занимавший порт 8765, не изменялся.

## Что не проверялось

Веса FashionCLIP не скачаны, нейросетевое индексирование фотографий не запускалось: текущий рейтинг основан на метаданных. Реальная отправка в Telegram не выполнялась без пользовательского токена и chat ID; ежедневный запуск выключен. Рассылка работает только при запущенном приложении. Обход защиты не реализован. Не проверены круглосуточная устойчивость, полнота каталога, публичный многопользовательский доступ и доступ с другого устройства.
