# freshhead ↗

**Не просто вещи. Твой следующий образ.**

Личный веб-каталог одежды: находки из нескольких магазинов, обучение на лайках и комплекты **верх + брюки + обувь**. Русский интерфейс, адаптивная вёрстка, локальная база SQLite. Оценка вкуса отделена от оценки сочетания.

> Версия 0.1 — локальный однопользовательский прототип, не публичный SaaS. Встроенные демо-вещи — оригинальные вымышленные иллюстрации, а не ассортимент магазинов. Они отдельно помечены и никогда не попадают в настоящую рассылку.

## Запуск

Нужен **Python 3.11+** и интернет для установки зависимостей / чтения магазинов.

**Windows:** скачай репозиторий, распакуй и запусти `start.bat`. Он создаст `.venv`, установит зависимости и запустит приложение. Открой **http://127.0.0.1:8766**. Окно терминала должно оставаться открытым.

**macOS / Linux:**

```bash
git clone https://github.com/lomatoq/freshhead.git
cd freshhead
bash run.sh
```

Ручной запуск после установки зависимостей:

```bash
python -m freshhead
```

Используй Python из `.venv`. На Windows это `.venv\Scripts\python.exe`, на macOS/Linux — `.venv/bin/python`.

## Как пользоваться

1. В **Магазинах** запусти проверку одного источника. Приложение покажет результат, ошибки и число обработанных карточек. Первый проход занимает время: между запросами есть пауза.
2. В **Твоём вкусе** поставь 20–50 лайков и несколько дизлайков. Клавиши: `→` нравится, `←` не нравится, `↓` пропустить; есть отмена. Оценки сохраняются после перезапуска.
3. В **Образах** выбери вещь, вокруг которой нужен комплект, и режим пропорций. Можно сохранить целый образ, открыть отдельную вещь или перейти в магазин.

В пустом каталоге доступна отдельная кнопка демонстрации интерфейса. Лайки на демо не обучают рейтинг реального ассортимента. Демо можно удалить одним действием.

## Магазины

Настроены адаптеры публичных страниц **EME Studios**, **Supersklep**, **Jaded London**, **Walk in Paris**. Дополнительные два источника выбраны как направления для свободного денима, необычных фактур и более спокойного городского гардероба; это не гарантия совпадения с личным вкусом.

EME подключён к публичной US-витрине; Jaded может перенаправить на региональную версию. Цена остаётся в валюте полученной страницы, а не выдаётся за польскую. Доставку и окончательную цену проверь после выбора Польши у продавца.

Сборщик читает JSON-LD, карточки каталога и Open Graph. Сохраняет название, бренд, изображения, URL, цену/валюту, известные варианты размеров/наличия, метод извлечения и дату проверки. Неизвестные поля остаются неизвестными.

**Проход ограничен бюджетом запросов, а не обходит весь магазин.** По умолчанию — до 24 запросов на источник. Сначала читаются стартовые категории, затем детальные страницы; при следующих проходах приоритет получают карточки с неполными или более старыми данными. Полная пагинация всех категорий пока не реализована.

`robots.txt` проверяется до страниц; запрещённые пути, CAPTCHA, HTTP 401/403/429 и междоменные перенаправления прекращают обход. Если `robots.txt` недоступен, источник пропускается. Приложение не обходит защиту, не использует прокси-ротацию и закрытые API. Изменения вёрстки могут потребовать корректировки адаптера. Статус проверки означает результат конкретного прохода, а не обещание постоянного доступа.

Для обычной страницы, которой нужен JavaScript, существует дополнительный браузерный режим. Он **не запускается после блокировки**:

```bash
python -m pip install -r requirements-browser.txt
python -m playwright install chromium
```

После установки включи браузерный fallback в настройках. Строгая фильтрация сетевых запросов браузера может сделать некоторые JS-сайты несовместимыми. Это не универсальный обход антибота.

## Вкус и сочетания: что именно считается

**Базовая версия работает без нейросети.** Из названий и описаний извлекаются предположительные категории, силуэты, цвета, фактуры и другие признаки. Рейтинг вкуса сравнивает вещь с несколькими лайками своей категории и учитывает дизлайки. Это предпочтительнее одного общего «среднего» между куртками и кроссовками, но всё ещё эвристическая модель.

**Образы оцениваются отдельно:** совместимость пропорций, объём обуви, повтор цвета, акценты, принты и фактуры. Доступны баланс объёмов, контраст пропорций и свободный силуэт. У каждого комплекта есть объяснение, происхождение правил и указание ограниченности данных. Число 0–100 — внутренний сравнительный индекс, **не вероятность понравиться и не экспертный вердикт**.

Правила вдохновлены конкретными материалами о пропорциях; собственные эвристики отмечены отдельно. Это **не модель, обученная на образах стилистов**, и не симуляция посадки на теле. Источники и границы интерпретации: [docs/STYLE_GUIDE.md](docs/STYLE_GUIDE.md).

### Дополнительное сравнение по фотографиям

Есть опциональный индекс **FashionCLIP** (`patrickjohncyh/fashion-clip`). Он скачивается только при явном запуске команды, не при открытии приложения:

```bash
python -m pip install -r requirements-vision.txt
python -m freshhead index-images --limit 100
```

Сначала собери реальные товары. Команда обрабатывает разрешённые изображения из локального каталога и сохраняет эмбеддинги. Если у сравниваемой пары есть эмбеддинги, рейтинг использует их вместе с метаданными; иначе остаётся текстовый fallback. Можно повторять индексацию после новых поступлений: неизменившиеся фотографии не пересчитываются.

Первый запуск требует интернета, загрузки модели и заметно больше памяти. Производительность зависит от CPU/GPU. **В поставленных тестах веса модели не загружались: базовые сценарии проверены отдельно от этого дополнительного режима.** FashionCLIP помогает сравнивать внешнее сходство, но не превращает правила сочетаний в визуально обученного стилиста. OpenJev в эту версию не интегрирован.

## Размеры, бюджет, наличие

В настройках — отдельные бюджеты PLN/EUR/GBP/USD, пол/категория, сезон и размеры. Валюты не складываются и не пересчитываются по выдуманному курсу. Можно скрывать товары с неизвестным размером строгим фильтром. Без строгого фильтра неопределённость видна в карточке.

Нельзя достоверно вывести индивидуальную посадку из размера M или фотографии. Доставку в Польшу и окончательную цену/наличие необходимо проверить у продавца: география, валюта и варианты могут зависеть от региона сайта.

## Ежедневная подборка

Раздел **На сегодня** собирает новую подборку по текущему вкусу. Перед включением отдельных товаров повторно читаются их страницы; недоступные для проверки позиции пропускаются. Рядом могут отображаться комплекты из базы, но их состав не проходит отдельную полную перепроверку всех компонентов.

Автоматический запуск **изначально выключен**. Включается в настройках; по умолчанию 09:00, `Europe/Warsaw`. Планировщик работает **только пока запущено приложение и компьютер не спит**. После запуска позже выбранного времени он может выполнить пропущенную подборку за текущий день. Это не облачная подписка и не задача ChatGPT.

Без Telegram подборка сохраняется в приложении. Для отправки создай `.env` по примеру `.env.example` и укажи собственные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`; затем перезапусти приложение. Ни токен, ни chat ID не отправляются в браузер и не включаются в экспорт. Сообщения содержат карточки товаров, цену, бренд, ссылку и предпросмотр изображения, если Telegram его покажет. Полные визуальные коллажи комплектов в Telegram пока не отправляются.

Успешно отправленные товары записываются в SQLite и не повторяются. При частичном сбое повторная отправка пропустит подтверждённые сообщения. Если сеть оборвалась после приёма сообщения Telegram, но до ответа клиенту, возможен один повтор: абсолютная exactly-once доставка не гарантируется.

## Данные и безопасность

По умолчанию база находится в `data/`; путь можно изменить через `FRESHHEAD_DATA`. В ней хранятся предпочтения, каталог, сохранённые образы и история отправок. Есть экспорт JSON. `.env`, база, кэши и веса не коммитятся.

Сервер слушает **127.0.0.1**, а не весь интернет. Проверяются Host, Origin и заголовок записи; импорт URL ограничен списком магазинов. Это не замена авторизации. Для доступа с телефона нужен отдельно настроенный безопасный доступ: адаптивный интерфейс уже есть, но LAN/public-сервер по умолчанию намеренно не открыт. Для многопользовательского или публичного развёртывания сначала добавь авторизацию, TLS, разделение данных и защиту секретов.

Запускай один экземпляр приложения на одну базу. Не запускай параллельно сервер и CLI-сборщик с тем же `FRESHHEAD_DATA`.

## Команды и тесты

```bash
python -m freshhead refresh --store supersklep
python -m freshhead digest
python -m freshhead digest --send
python -m freshhead demo
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

`refresh`, `digest` и `index-images` — разовые CLI-команды, не создание фоновой службы. Telegram используется только с `--send` или включённым планировщиком/явной отправкой в интерфейсе.

Подробности проверки и ограничения — [docs/TESTING.md](docs/TESTING.md). Сторонние фотографии и данные не перелицензированы; MIT распространяется на оригинальный код приложения и оригинальные демо-иллюстрации.
